Hi, I'm Dr. Chuck. Welcome to Python for Everybody with AI. This is a practical Python course that starts with the fundamentals of programming without AI assistance. Once you have a solid foundation, we'll introduce AI as a tool for learning Python and then use AI to tackle more advanced programming projects. The course includes readings, videos, exercises, assignments, weekly communication, and live help. There are no university grades or credit, and you can keep working after the campus semester ends. The goal is to help online learners build real programming skills, learn to use AI effectively, and stay connected and motivated along the way.

The course will start January 1st, 2027, enrollment will be limited to the first 200 students, and registration will be closed January 21st, 2027.
